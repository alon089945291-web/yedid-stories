# yedid-stories

סטטוסים לאתר ידיד נפש.

- `story-status.js` – הקוד של הסטטוסים (מוטמע באתר בשורה אחת)
- `stories.json` – הסטטוסים וההגדרות (מתעדכן אוטומטית מפאנל הניהול)
- `media/` – תמונות וסרטונים (נוצרת אוטומטית בהעלאה הראשונה)
- `index.html` – דף קטן לכניסת מנהל

כניסת מנהל: `https://alon089945291-web.github.io/yedid-stories/#status-admin`
